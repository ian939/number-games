# 컨텍스트 노트 — 칠교 게임

## 원본 분석 (왜 "딱딱하고 매칭 안 됨")
- 회전: 더블탭 45°(거침) + 두 손가락 핀치(6세 불가) + 휠 15°. → 6세는 회전 자체가 난관.
- 스냅: SNAP_THRESHOLD=15px로 빡빡, 위치만 스냅하고 각도는 스냅 안 함 → 어중간한 각도면 영영 안 맞음.
- 판정: shadow(빨강) vs 조각(파랑) source-in 픽셀 합성 후 97% 커버 = 성공.

## 우리 설계 결정
- decision_id: ROT-BTN
  내용: 회전은 선택 조각 옆 떠오르는 큰 버튼, 탭마다 +45° easeOutCubic 애니메이션(160ms).
  근거: 6세는 핀치/더블탭 불안정. 단일 큰 버튼이 가장 실수 적음. 45° 스텝이면 항상 깔끔한 각도 → 매칭 신뢰도↑.
- decision_id: SLOT-SNAP
  내용: 슬롯 기반 매칭. 조각 id ↔ 동일 id 슬롯 1:1. 놓을 때 위치 30px·각도 0.30rad 이내면 슬롯으로 흡착 애니메이션 후 lock.
  근거: 원본의 픽셀 커버 방식보다 6세에게 "여기 딱 들어감" 피드백이 명확. id 1:1이라 모호성 없음.
  영향: 각도는 조각 회전 대칭(사각형 π/2, 평행사변형 π, 삼각형 2π) 고려해 mod 비교.
- decision_id: POINTER
  내용: Pointer Events + touch-action:none. 마우스+터치 통합으로 더블파이어 제거.
  근거: 원본은 mouse/touch 병행 → 더블파이어 위험(프로젝트 Gotcha). iPad Safari Pointer 지원.

## 좌표계
- 원본 좌표계 재사용(CANVAS 900×500, 조각 정의·정사각형 솔루션 데이터 그대로) → 솔루션 기하 정확성 보장.
- 캔버스 폭만 980로 확장해 오른쪽 조각함 여유 확보(왼쪽 슬롯 좌표는 불변).
- 정사각형 슬롯 회전값: id5=5π/4, id6=3π/4, 나머지 π/4 (원본 추천데이터 mod 2π).

  근거: 사용자 요청. 흑백은 정통 칠교 느낌, 컬러는 6세용 보조.
